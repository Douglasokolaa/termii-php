# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅ Security fixes |
| < 2.0   | ❌ Not supported |

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Report it privately via [GitHub Security Advisories](https://github.com/Douglasokolaa/termii-php/security/advisories/new),
or email **okolaadouglas@gmail.com** with `[SECURITY] termii-php` in the subject.

Please include the affected version, a description of the impact, and steps to reproduce.
You should get an acknowledgement within a few business days. Fixes are released as a patch
version and announced in a GitHub Security Advisory.

Issues in the Termii API itself should be reported to Termii.
